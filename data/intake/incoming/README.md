# Incoming source files

Place copies of unreviewed source files in this folder for initial review,
including PDFs and CSVs. Keep their original filenames and contents; do not
assume CSV files share a schema or combine them before they have been inspected.

After the files are available, review PDF claims against the cited pages,
tables, or figures, and inspect CSV columns and contents. Map each file to the
appropriate source, paper, or observation records, and document any
transformations. Only reviewed observation data should be prepared as
`data/raw/environmental_data.csv` for the pipeline. Keep the supplied sample
and the original incoming files unchanged.

PDF files in this folder are ignored by Git because reports and research papers
may be copyrighted. Keep local copies for source verification and use the source
register's public URLs and page/table locators when sharing the project.
